mamba_ssm은 설치하지 않아도 된다 (맥에서는 못 한다)

RoboMamba 저장소 requirements.txt는 mamba_ssm==2.2.0과 causal_conv1d를 요구한다. 둘 다 CUDA 커널을 컴파일하므로 Apple Silicon에서는 빌드되지 않는다.

그런데 필요 없다 transformers가 순수 PyTorch 대체 경로를 갖고 있다. 실행하면 이런 안내가 뜨는데 정상이다:

`selective_scan_fn` is falling back to its reference PyTorch implementation because `mamba_ssm` is not installed. This is correct but much slower; install `mamba_ssm` for the optimized kernel.

"This is correct but much slower" — 결과는 같고 속도만 느리다. 위의 MPS 속도는 모두 이 대체 경로로 측정한 값이다.

코랩(T4 GPU)에서는 pip install mamba-ssm causal-conv1d가 가능하다(미검증). 다만 스터디 목적에는 불필요하다.
