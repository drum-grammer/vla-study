RoboMamba — 이해가 먼저, 조작은 싸게

트랜스포머 대신 선형 복잡도의 Mamba를 LLM으로 쓴 VLA. 일반 VQA와 로봇 VQA를 섞어 학습해 추론 능력을 먼저 확보하고, 그 뒤에는 백본을 완전히 동결한 채 MLP 헤드 두 개(모델의 0.1%)만 파인튜닝해 SE(3) 포즈 예측을 붙인다. FiS-VLA의 출발점이자, "추론 능력이 충분하면 조작은 최소 비용으로 붙는다"는 명제의 원천이다.

RoboMamba: Efficient Vision-Language-Action Model for Robotic Reasoning and Manipulation. Jiaming Liu 외 — 베이징대 · AI² Robotics · BAAI. arXiv 2406.04339 (v1 2024-06-06 / v2 2024-12-14), NeurIPS 2024 채택. 제1저자 Jiaming Liu는 FiS-VLA의 프로젝트 리드이기도 하다. 코드는 MIT 라이선스이나 학습 코드는 비공개(저자 메일 요청).

기여 세 가지 (논문 1절)

  1. 비전 인코더 + 선형 복잡도 Mamba LLM을 결합한 종단간 VLA.

  3. 일반·로봇 추론 벤치마크와 시뮬·실기 포즈 예측에서 검증.

1.1먼저 알아야 할 개념 여섯 개

각 항목의 링크는 정독 가이드 1부의 해당 절이다. FiS-VLA 페이지를 먼저 읽었다면 앞 둘은 건너뛴다.

토큰과 임베딩이미지 패치·언어를 같은 크기의 벡터 열로 만들어 세로로 쌓는다. RoboMamba는 [이미지 256, 텍스트 ~15] 순서다 — 이 순서가 실습 4의 주제. → 가이드 1.2
트랜스포머와 어텐션 — 그리고 왜 느린가모든 토큰이 모든 토큰을 본다 → 계산이 L². 토큰을 하나 더 뽑을 때마다 지금까지의 전부(KV 캐시)를 다시 읽는다. → 가이드 1.3
순환신경망과 상태 — SSM의 조상고정 크기 상태 h를 들고 토큰을 하나씩 흘린다. 계산 O(L), 생성 시 메모리 고정. 대신 "무엇을 기억할지"를 고를 수 없었다. → 가이드 1.4
Mamba — 선택적 상태공간모델(S6)B·C·Δ를 입력의 함수로 만들어 토큰마다 "기억할지 넘길지"를 정한다. Δ가 크면 과거를 지우고, 작으면 보존. → 가이드 1.5
MLLM — 이미지를 LLM에 넣기CLIP → 프로젝터(MLP) → LLM. RoboMamba는 비전 인코더 앙상블을 일부러 거부했다. → 가이드 1.6
개루프 vs 폐루프, 관절 물체, 파인튜닝 전략RoboMamba는 한 번의 접촉 포즈를 내는 개루프 예측이다(궤적 제어가 아니다). 무엇을 동결하고 무엇을 학습하는가가 논문의 핵심 선택. → 가이드 1.8 · 1.10

1.2문제 — 두 개의 약점 (초록 · 1절)

약점내용논문의 답
추론이 약하다사전학습 MLLM의 로봇 장면 추론 능력이 부족해 복잡한 과제에서 무너진다 (그림 1의 "1- 끝" 예시)일반 VQA + 로봇 VQA(RoboVQA 300K) 공동학습으로 추론 능력을 먼저 갖춘다
비싸다어텐션 기반 LLM 때문에 파인튜닝도 추론도 비용이 크다 (OpenVLA 7B 3.4 Hz, ManipLLM 1.1 Hz)백본을 Mamba로 바꾸고, 조작은 3.7M 헤드만 학습한다

1.3핵심 아이디어 — 그림 1 읽기

그림 1은 두 부분이다. 왼쪽은 속도 막대(9.0 vs 3.4 vs 1.1 Hz), 오른쪽은 추론 예시. 논문의 주장은 두 겹이다: (1) Mamba라서 빠르다 — 선형 복잡도. (2) 이해가 먼저다 — 추론 능력이 갖춰지면 조작은 작은 헤드로 충분히 붙는다. (2)가 이후 FiS-VLA를 포함한 모든 후속 논문의 전제가 되므로, 그 근거가 얼마나 단단한지를 1.8·1.9절에서 따진다.

비유 트랜스포머는 문장을 읽을 때 매 단어마다 앞 단어 전부를 다시 훑는 독자, Mamba는 "요약 메모 한 장"(고정 크기 상태)만 갱신하며 읽는 독자다. Mamba가 다른 점은 메모에 무엇을 적고 무엇을 지울지를 지금 읽는 단어가 정한다는 것. 더 깊이: 가이드 2.3

1.5Mamba를 쓴 이유 — 식 (1)~(4) (3.1절)

식 (1)(4) · 상태공간모델의 순환 
h_t = Ā h_{t−1} + B̄ x_t          y_t = C h_t
Ā = exp(ΔA)         (식 2)       B̄ = (ΔA)⁻¹ (exp(ΔA) − I) ΔB ≈ ΔB   (식 3, 저장소는 근사)

고정 크기 상태 h를 들고 토큰을 하나씩 흘린다 → 계산 O(L), 생성 시 메모리 고정. Δ가 크면 Ā ≈ 0이라 과거를 지우고 지금을 받고, 작으면 Ā ≈ 1이라 과거를 보존한다.

Mamba(S6)는 여기에 B·C·Δ를 입력의 함수로 만들었다. 그래서 "이 토큰은 기억하고 저 토큰은 넘기기"가 가능하다 — 논문이 말하는 content-aware reasoning. 블록 하나는 in_proj → conv → x_proj/dt_proj → 선택적 스캔 → out_proj. 더 깊이: 가이드 1.5

실습 1 · 2 · 3실습 1은 식 (1)~(4)를 숫자로 굴리고 Δ가 기억 길이를 정하는 것을 본다. 실습 2는 어텐션 O(L²) vs 스캔 O(L)을 실측한다. 실습 3은 '선택'이 없으면 못 하는 일을 만든다. → 2.1 · 2.2 · 2.3

1.9한계와 비판적으로 읽기

논문이 밝힌 것 (5절) — 딱 하나

2.7B LLM이라 7B/13B 기반 MLLM보다 복잡한 추론에서 뒤진다. 향후 ① 더 발전된 선형 복잡도 LLM, ② 4D 로봇 VLA(포인트클라우드 + 시간). ②가 그대로 FiS-VLA의 설계가 된다.

논문이 밝히지 않은 것 — 스터디에서 따져 볼 것

  1. 개루프 실험인데 "control frequency"라 부른다. 폐루프 제어 실험은 없다.
  2. 파라미터 수가 코드와 안 맞는다. 표 6의 3.7M을 공개 코드로 세면 8.20M, 45.2M은 90.69M (실습 6). 결론(크기 무관)은 유지되지만 재현에 걸린다.
  3. 부록 표 4의 인코더 라벨이 상충한다. 인쇄된 2행(XCiT 224)의 값이 표 1의 RoboMamba 224 행과 정확히 같고, 본문은 XCiT가 나쁘다고 적는다 → 1·2행 라벨이 바뀐 것으로 보인다(확인 2026-09-11).
  4. 식 (6)의 바닥이 막혀 있다. 4.1절이 데이터 수집 시 y축을 임의로 정하므로 정답 회전의 z축 주위 성분은 장면의 함수가 아니다. 흡착 그리퍼라 성공률에는 영향이 거의 없지만(실습 5: 회전 오차 93.7°에 멈추는데도 성공률 95.5%), 식 (6)을 지표로 쓰면 모델 비교가 안 된다.
  5. co-training 주장이 증거보다 강하다. "일반 추론도 좋아진다"지만 부록 표 5에서 GQA는 세 쌍 모두 내려간다.
  6. "이해 → 조작" 인과의 통제. 그림 3b의 백본 네 개는 크기·구조·데이터가 모두 다르다. 통제된 비교는 co-training 유무 한 쌍뿐.
  7. 동결의 대가를 재지 않았다. "헤드만 vs 백본도 조금" 대조 실험이 없다.
  8. 공개 범위. 학습 코드·조작 평가·데이터 수집 스크립트 모두 없다. 같은 회사가 공저자인 FiS-VLA는 학습·평가를 모두 공개했다.

2.9실제 모델 · 알려진 한계

실제 Mamba 백본 확인(노트북 부록). state-spaces/mamba-*-hf를 transformers로 불러 토큰을 흘려 본다. Apple Silicon은 MPS로, 코랩은 T4로 돈다. mamba_ssm은 설치하지 않아도 되고(맥에서는 못 한다), 저장소 체크포인트는 test 브랜치에 있다. 조건과 절차는 실습 환경 페이지.

실습의 알려진 한계

  • 실습 3은 Δ를 학습하지 않고 격자탐색으로 각 구조의 최적값을 찾아 비교한다. 실제 Mamba가 학습으로 그 최적에 도달한다는 뜻은 아니다.
  • 실습 4의 민감도 수치는 무작위 가중치 축소 모형이다. 방향성만 읽어야 한다.
  • 실습 5는 장난감 장면이다. 논문 표 2의 성공률을 재현한 것이 아니다.
  • 실습 2의 절대 시간은 numpy 단일 스레드 값으로 GPU 속도와 무관하다. 증가율만 본다.
  • 저장소 줄 번호는 2026-09-11 main 기준.

3.2공유회에서 던질 질문 세 개

  1. "이해가 먼저"라는 인과는 얼마나 증명됐는가? 그림 3 b)의 백본 네 개는 크기·구조·데이터가 모두 다르다. 통제된 비교는 co-training 유무 한 쌍뿐이다. 이 명제가 FiS-VLA 이후 모든 논문의 전제가 되는데, 근거가 충분한가? (1.8 · 1.9절)
  2. 왜 백본이 Mamba에서 트랜스포머로 되돌아갔는가? 논문 5절은 "더 발전된 선형 복잡도 LLM으로"라 했는데 후속(FiS-VLA)은 LLaMA2를 쓴다. 표 1의 MME·MMBench 열세, [이미지, 텍스트] 순서 비대칭(실습 4), 아니면 다른 이유인가? (1.10절)
  3. "헤드만 3.7M(0.1%)"의 효율과 "백본을 못 고친다"의 대가는 어떻게 저울질되는가? 표 6은 헤드를 12배 키워도 같다고 한다. 그러면 병목은 백본 표현인데, 논문에 "헤드만 vs 백본도 조금" 대조 실험이 없다. FiS-VLA가 굳이 백본을 함께 학습한 것(L_slow)은 이 대가를 인정한 것인가? (1.8 · 1.9 · 1.10절)

3.3자가 점검 퀴즈 10문항

논문을 읽고 나서 푼다. 8개 이상이면 공유회 준비 완료.

  1. Mamba가 S4 같은 이전 SSM과 다른 점을 한 문장으로.
  2. Δ(시각 간격)가 크면 상태에 무슨 일이 일어나는가? 작으면?
  3. RoboMamba가 받는 입력은 무엇인가? FiS-VLA가 추가로 받는 것 두 가지는?
  4. 학습 3단계에서 각각 무엇을 학습하고 무엇을 동결하는가?
  5. 논문 식 (5)와 (6)은 각각 어떤 손실이고 무엇을 예측하는가?
  6. 표 2에서 RoboMamba의 seen/unseen 평균과 ManipLLM 대비 차이는?
  7. "3배 빠르다"와 "7배 빠르다"는 각각 무엇 대비인가?
  8. 그림 3 b)에서 co-training을 뺐을 때 seen과 unseen 중 어디가 더 떨어지는가? 왜 중요한가?
  9. 정책 헤드의 파라미터를 12배 키우면 성공률은? 이 결과가 뜻하는 바는?
  10. 논문이 밝힌 한계 하나와, 밝히지 않은 한계 하나를 들어라.
  1. B·C·Δ를 학습된 상수가 아니라 입력의 함수로 만들어, 토큰마다 "기억할지 넘길지"를 정할 수 있게 했다(선택적 스캔, S6).
  2. Δ가 크면 Ā = exp(ΔA) ≈ 0 → 과거를 지우고 지금 입력을 크게 받는다. Δ가 작으면 Ā ≈ 1 → 과거를 보존하고 지금 입력을 거의 무시한다. (실습 1: Δ=0.02는 55토큰, Δ=2.0은 2토큰까지 기억)
  3. RGB 이미지 한 장 + 언어 질문뿐이다. FiS-VLA는 추가로 3D 포인트클라우드와 로봇 상태를 받는다(이미지도 3장).
  4. Stage 1.1: Project Layer만 학습, 비전 인코더·Mamba 동결. Stage 1.2: Project Layer + Mamba 학습, 비전 인코더 동결. Stage 2: 정책 헤드만 학습, 나머지 전부 동결.
  5. 식 (5) = 접촉점 위치의 L1 손실. 식 (6) = 그리퍼 방향의 측지 거리(두 회전 사이 각도) = arccos((Tr(R_gtᵀR_pred) − 1)/2).
  6. seen 0.63 / unseen 0.53. ManipLLM(0.56 / 0.51) 대비 +7%p / +2%p. 20개 중 14개 SOTA.
  7. 초록의 "3 times"는 OpenVLA 대비(3.4 → 9.0 Hz). 4.2절의 "7 times"는 LLaMA-AdapterV2 / ManipLLM 대비(1.1 → 9.0 Hz).
  8. unseen이 더 크게 떨어진다(0.53 → 0.41 vs seen 0.63 → 0.61). 로봇 데이터를 섞는 이득이 주로 일반화에 있다는 뜻이다.
  9. 63.7% → 63.2%로 거의 같다(부록 표 6, (SSM block+MLP)×2 = 45.2M). 병목이 헤드가 아니라 백본의 표현에 있다는 뜻이고, 그래서 "이해가 먼저"라는 주장을 받친다.
  10. 밝힌 것: 2.7B LLM이라 복잡한 추론에서 7B/13B 기반 MLLM에 뒤진다(5절). 밝히지 않은 것(예): 개루프 단발 예측인데 "control frequency"라 부른 것, 데이터 수집의 임의 y축 때문에 식 (6)의 바닥이 막힌 것, co-training이 GQA를 일관되게 떨어뜨린 것, 논문↔코드 파라미터 불일치, 동결의 대가를 재는 대조 실험 부재.
