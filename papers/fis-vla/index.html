FiS-VLA — 빠른 손을 느린 머리 안에 넣다

온전한 VLM(LLaMA2-7B, 32블록)을 느린 System 2로 그대로 쓰고, 그 마지막 블록 2개를 빠른 System 1(확산 행동 생성기)로 재활용한다. 두 시스템은 다른 입력을 받고 1:4 주기로 돌며, 확산 손실과 자기회귀 손실을 함께 학습한다. 이 페이지 하나로 개념 → 실습 → 공유회 준비까지 간다. 더 깊이 볼 곳은 정독 가이드의 절로 링크했다.

Fast-in-Slow: A Dual-System Foundation Model Unifying Fast Manipulation within Slow Reasoning. Hao Chen, Jiaming Liu, Chenyang Gu, Zhuoyang Liu 외 — CUHK · 베이징대 · AI² Robotics · BAAI. arXiv 2506.01953, 2025-06-02. 회사가 오픈소스 모델 "GOVLA 0.5"의 원형으로 내세우는 논문(2차 출처). 실기 실험 중 AlphaBot 결과가 제품과 가장 가깝다.

기여 세 가지 (논문 1절)

  1. Fast-in-Slow 구조 — 두 시스템이 같은 파운데이션 모델에서 나온다. System 1은 System 2의 일부다.
  2. 이종 입력 + 비동기 주파수 — System 2는 언어 + 2D 이미지(저주파), System 1은 2D 이미지 + 3D 포인트클라우드 + 로봇 상태(고주파). 비율 1:4.
  3. 이중 인식 공동학습(dual-aware co-training) — L = L_fast(확산 노이즈 예측) + L_slow(다음 토큰 예측). 후자가 없으면 System 2의 추론 능력이 망각된다.

논문에서 볼 곳: 초록, 그림 1(아이디어), 그림 2(4쪽 전체 구조도). 그림 2의 범례(언어·이미지·포인트클라우드·상태·노이즈 행동 토큰의 색)를 먼저 익혀 두면 뒤가 편하다.

1.1먼저 알아야 할 개념 여섯 개

각 항목의 링크는 정독 가이드 1부의 해당 절이다. 이미 아는 것은 건너뛴다.

토큰과 임베딩언어·이미지 패치·로봇 상태·노이즈 행동을 전부 "같은 크기의 벡터 열"로 만들어 한 행렬에 세로로 쌓는다. 트랜스포머는 그 행렬만 본다. → 가이드 1.2
트랜스포머 블록어텐션(닮은 토큰의 정보를 더 많이 섞는 가중평균 — Q·K로 닮음을 재고 V를 평균한다) + MLP. 입력과 출력 모양이 같아서 어느 블록 사이에서든 중간 표현을 꺼낼 수 있다. FiS-VLA의 핵심 전제. → 가이드 1.3 · 숫자 예제 1.3.1

확산 행동 헤드와 행동 청크노이즈에서 행동을 복원한다. 두 갈래 시연(왼쪽/오른쪽)을 회귀는 가운데로 뭉개고 확산은 갈래를 지킨다. 청크는 한 번에 H 스텝을 내는 것. → 가이드 1.8

기존 접근장점한계

1.3핵심 아이디어 — 그림 1 읽기

그림 1은 세 칸이다. 왼쪽이 단일 VLA(느림), 가운데가 기존 이중 시스템(System 1이 VLM 밖), 오른쪽이 FiS-VLA — System 1이 VLM의 꼬리 블록 안에 들어가 있다. 그림에서 확인할 것 두 가지: (1) System 1로 들어가는 화살표가 System 2보다 많다(고주파 입력이 추가된다). (2) 두 시스템의 시계가 다르다(1:4).

비유 느린 머리(System 2)가 "지금 어느 단계인지"를 4스텝에 한 번 정리해 주면, 빠른 손(System 1)은 매 스텝 최신 위치와 3D 장면을 보고 움직인다. 손은 머리와 같은 뇌 조직(마지막 블록)이라 머리가 배운 것을 그대로 쓴다. 더 깊이: 가이드 2.3

1.5두 시스템의 조율 — 1:4 비동기와 이종 입력 (3.3절)

System 2는 90 ms급, System 1은 30 ms급이라고 치자. 매 스텝 둘 다 돌리면(1:1) 느리고, System 2를 너무 드물게 돌리면(1:16) 손이 "낡은 이해"로 움직인다. 사이 어딘가에 최적점이 있고 논문은 1:4를 택했다(부록 표 8: 1:1 0.60 · 1:2 0.63 · 1:4 0.69 · 1:8 0.61).

이종 입력이 중요한 이유: 고주파로 바뀌는 정보(로봇 상태, 3D 장면)를 System 2에 넣으면 4스텝 동안 낡는다. 그래서 System 1에만 넣는다. 부록 표 10의 "입력 배치 변형"이 이것을 검증한다(1.8절). 더 깊이: 가이드 2.5

실습 4점 로봇 모형에서 비율을 1:1 ~ 1:16으로 바꿔 성공률이 1:4 근처에서 최고가 되는 것, 그리고 청크를 늘리면 명령 Hz만 오르고 관측 Hz는 그대로인 것을 본다. → 2.4

1.6학습 — 식 세 개와 레시피 (3.4절)

식 (1) · L_fast — 확산 노이즈 예측 
L_fast = E_{a, ε, τ} ‖ ε − ε_θ( a_τ , τ , c ) ‖²
   a_τ = √ᾱ_τ · a + √(1−ᾱ_τ) · ε        (정답 행동 청크 a 에 노이즈 ε 을 τ 단계만큼 섞는다)
   c   = System 2 중간 특징 + 2D 이미지 + 3D 포인트클라우드 + 로봇 상태

System 1(블록 31~32)이 "섞인 노이즈가 무엇이었나"를 맞힌다. 추론 때는 순수 노이즈에서 시작해 이 예측으로 되감아 행동 청크를 만든다. 저장소 models/vlas/fisvla.py 204~236행의 네 줄이 그대로 이 식이다.

식 (2) · L_slow — 자기회귀 다음 토큰 예측 
L_slow = − Σ_t log p_θ( y_t | y_<t , 언어 , 2D 이미지 )      y = 이산 행동 토큰 또는 언어 계획

System 2가 원래 하던 일. 이것을 계속 학습시켜야 블록 1~30이 "노이즈 예측기의 부속품"으로 변하지 않는다.

식 (3) · 이중 인식 공동학습 
L = L_fast + L_slow

L_slow를 빼면 0.69 → 0.62 (4.2절 (4)). 저장소 training/strategies/base_strategy.py 312~313행 if ar_diff_loss: loss = loss + output.loss. 더 깊이: 가이드 2.6

논문이 밝힌 것 (5절, 부록 D)

  • System 1 블록 수와 주파수 비율이 고정. 태스크·환경에 따라 동적으로 바꾸는 것이 후속 과제.
  • 실기 실패 4종: 양팔 충돌, 얇은 변형 물체의 높이 오차, 물체 위치 오인, 건네주기 회전 오차. System 2가 실패를 인식·수정하는 능력이 미래 과제.

논문이 밝히지 않은 것 — 스터디에서 따져 볼 것

  1. 117.7 Hz는 이론값이다. 청크 8을 한 번에 내는 값이라 새 관측을 보는 빈도는 21.9 Hz급 그대로다.
  2. 속도 비교 조건. 베이스라인 속도는 청크 1로 통일 측정. π0는 원래 긴 청크를 쓰는 모델이라 불리할 수 있다.
  3. 규모 차이. π0(2.6B) vs FiS-VLA(7B). 논문도 각주로 인정.
  4. "System 1이 VLM 지식을 물려받는다"의 증거는 간접적(블록 수 소거, L_slow 소거, 일반화 하락 폭). 같은 크기의 별도 트랜스포머 블록 2개를 붙인 대조군과 직접 비교한 표가 없다.
  5. 두 시스템을 같은 GPU에서 순차 실행했다 — Helix처럼 병렬 배치가 아니다. 제품에서는 어떤지가 부스 질문.
  6. arXiv v1 기준. 학회 채택 여부·후속 판 미확인(2026-09-11).

2.8GPU가 있다면 · 알려진 한계

실제 모델 실행(스터디 범위 밖, 참고). 저장소 README(확인 2026-09-11) 기준 — 디스크 2GB 이상, CUDA 12 GPU(7B 추론에 24GB급), Ubuntu 전제.

  1. git clone https://github.com/CHEN-H01/Fast-in-Slow (LIFT3D 포함 약 700MB)
  2. conda 환경 Python 3.10, pip install -r requirement.txt, 추가로 dlimp_openvla · openvla · pytorch3d · flash-attn 2.5.5
  3. CoppeliaSim 4.1 (RLBench용) 설치, LIFT3D/third_party/RLBench와 LIFT3D pip install -e .
  4. HuggingFace haosad/fisvla 체크포인트 다운로드
  5. test_rlbench.sh의 경로를 고치고 실행 — 기본 태스크 close_box, --slow-fast-ratio 4 --llm_middle_layer 30 --ddim-steps 4 --action-chunk 1, 에피소드 20

train.sh는 A800 8장 기준(배치 6/GPU, 300 에폭)이라 개인 GPU에서 학습은 현실적이지 않다. 스터디에서는 실습 6으로 코드를 읽는 것까지를 목표로 한다.

실습의 알려진 한계

  • 실습 4는 논문의 로봇·모델이 아니라 "순차 실행 비용"과 "이해가 낡는 비용" 두 힘만 뽑은 장난감이다. 최적 비율은 상수에 달려 있고, 논문의 1:4가 보편 상수라는 뜻이 아니다.
  • 실습 5의 "추론 능력"은 4클래스 분류로 대신했다. 논문의 L_slow는 LLM의 다음 토큰 예측이다.
  • 실습 2의 시간은 numpy 단일 스레드 값이라 GPU 트랜스포머의 절대 속도와 무관하다. 비율만 본다.
  • 저장소 줄 번호는 2026-09-11 main 기준. 실습 6은 앵커로 찾으므로 바뀌어도 동작하지만, 앵커 문자열 자체가 바뀌면 "찾지 못함"을 출력한다.

3.1대표자용 "그림 한 장" 지시서

손으로 그릴 구조도. 논문 그림 2를 단순화한다. 이 그림 한 장으로 1.3~1.6절이 모두 설명된다.

  1. 가로로 긴 상자 32칸
    "LLaMA2-7B 블록 1~32"라 쓴다. 1~30을 한 색, 31~32를 다른 색으로 칠하고 "System 1"이라 적는다
  2. 왼쪽 아래에서 상자 시작점으로 들어가는 화살표 두 개
    "언어 지시", "2D 이미지 (저주파, 4스텝마다)". 묶어 "System 2 입력"
  3. 블록 30과 31 사이 위에서 들어오는 화살표 네 개
    "2D 이미지", "3D 포인트클라우드", "로봇 상태", "노이즈 행동 a_t…a_{t+H}". 묶어 "System 1 입력 (고주파, 매 스텝)"
  4. 블록 32 오른쪽에서 나가는 화살표 두 개
    위: "노이즈 예측 → 확산 → 행동 청크 H개 (L_fast)". 아래: "다음 토큰 (이산 행동/언어) (L_slow)"
  5. 아래에 시간축 하나
    System 2는 4칸마다 점, System 1은 매 칸 점. "1:4"라 쓴다

3.2공유회에서 던질 질문 세 개

  1. System 1을 VLM 마지막 블록으로 만든 것과, 같은 크기의 새 트랜스포머 블록 2개를 붙인 것의 차이는 무엇인가? 논문의 증거는 무엇이고, 빠진 실험은 무엇인가. (1.9절 4번)
  2. 1:4 비율이 1:1보다 성공률이 높은 이유가 "속도" 때문인가 "학습 신호" 때문인가? 학습 때 비동기 샘플링을 했다는 점이 어떤 역할을 하는가. (1.5절, 실습 4)
  3. 부록 표 7에서 System 1 입력을 다 빼면 22%로 떨어진다. 이것이 기존 이중 시스템(π0, CogACT)에 대한 비판으로 성립하는가, 아니면 FiS-VLA 특유의 구조(마지막 2블록만 쓰는) 때문인가. (1.8절)

3.3자가 점검 퀴즈 10문항

논문을 읽고 나서 푼다. 8개 이상이면 공유회 준비 완료.

  1. FiS-VLA의 System 1은 어디에 있는가?
  2. System 2와 System 1의 동작 주파수 비율은? 그 비율을 정한 실험은?
  3. System 1이 받지만 System 2는 받지 않는 입력 두 가지는?
  4. L_fast와 L_slow는 각각 어떤 종류의 손실이고 무엇을 지키는가?
  5. "117.7 Hz"와 "21.9 Hz"의 관계를 한 문장으로 설명하라.
  6. RLBench에서 FiS-VLA의 평균 성공률과 CogACT·π0 대비 차이는?
  7. 실기 로봇 두 종과 각각의 제어 모드(포즈/관절)는?
  8. 사전학습 데이터 규모는?
  9. System 1 블록 수를 2에서 8로 늘리면 성공률은 어떻게 되는가?
  10. 논문이 스스로 밝힌 한계 하나와, 논문이 밝히지 않은 비교의 한계 하나를 들어라.
  1. LLaMA2-7B의 마지막 트랜스포머 블록 2개. 별도 모듈이 아니라 System 2 VLM의 일부.
  2. 1:4. 4.2절 (3), 부록 표 8. 1:1 0.60, 1:2 0.63, 1:4 0.69, 1:8 0.61.
  3. 3D 포인트클라우드, 로봇 상태. (2D 이미지는 양쪽 다 받는다.)
  4. L_fast는 확산 노이즈 예측 MSE로 행동 생성을 배우고, L_slow는 자기회귀 교차엔트로피로 System 2의 추론 능력(망각 방지)을 지킨다.
  5. 21.9 Hz는 청크 1일 때 모델 추론 속도이고, 117.7 Hz는 청크 8로 한 번에 8스텝을 낼 때의 이론 제어 주파수다.
  6. 0.69. CogACT(0.61) 대비 +8%p, π0(0.55) 대비 +14%p.
  7. AgileX 양팔 14-DoF 엔드이펙터 포즈 제어, AlphaBot 양팔 16-DoF 관절 위치 제어.
  8. 37개 데이터셋, 86만 궤적, 3,600만 프레임.
  9. 0.69 → 0.64로 떨어진다(4블록 0.66). 2개에서 포화.
  10. 밝힌 것: 블록 수·주파수 비율이 고정(5절). 밝히지 않은 것(예): 청크 1 통일 비교가 π0에 불리할 수 있음, 별도 헤드 대조군 부재, 7B vs 2.6B 규모 차이.
