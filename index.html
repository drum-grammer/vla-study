2논문 — 주제별 목록

스터디 페이지가 있는 논문은 그 한 장으로 개념·실습·공유회 준비를 끝낸다. 아직 없는 논문은 컬렉션 문서의 요약(문제 → 아이디어 → 구조 → 결과 → 한계)으로 읽는다. 링크는 arXiv 최신판 기준.

vla — 로봇 파운데이션 모델

  1. 2024-06arXiv 2406.04339

    RoboMamba NeurIPS 2024 · 정독 완료

    Mamba(상태공간모델) 백본으로 작고 빠른 VLA. 추론 능력을 먼저 갖추면 백본을 동결한 채 3.7M 파라미터 헤드만 학습해도 조작을 배운다는 가설을 세우고 검증했다. 태그: mamba ssm efficiency

    스터디 페이지정독 가이드실습 7개arXiv코드
  2. 2025-06arXiv 2506.01953

    Fast-in-Slow (FiS-VLA) preprint · 코드·가중치 공개 · 정독 완료

    느린 추론(System 2)과 빠른 실행(System 1)을 한 VLM 안에 넣는다. VLM의 마지막 트랜스포머 블록 2개를 실행 모듈로 재활용해 청크 8에서 117.7 Hz까지 냈다. 태그: dual-system diffusion-head action-chunk

    스터디 페이지정독 가이드실습 6개arXiv코드
  3. 2025-12arXiv 2512.03724

    PosA-VLA preprint · 요약

    로봇 손(엔드이펙터) 위치로 앵커 맵을 만들어 모델의 주의(attention)를 목표물에 고정한다. 궤적의 흔들림이 줄고 잡기 성공률이 오른다. 태그: attention-supervision flow-matching

    컬렉션 요약arXiv
  4. 2026-01arXiv 2601.14628

    NeuroVLA preprint · 코드 공개 · 요약

    피질·소뇌·척수 3층 구조. 소뇌 모듈이 팔 떨림을 잡고, 스파이킹 신경망 척수가 20 ms 미만의 안전 반사를 낸다. 태그: neuromorphic snn hardware

    컬렉션 요약arXiv코드

world-model — 세계모델 · 비디오 생성 기반 지각

  1. 2025-12arXiv 2512.03044

    Video2Act preprint · 코드 공개 · 요약

    비디오 확산모델의 특징에 Sobel(공간)과 FFT(운동) 필터를 걸어 "무엇을 만질지, 어떻게 움직일지"를 뽑아 행동 헤드에 공급한다. 태그: vla video-diffusion

    컬렉션 요약arXiv코드

perception — 3D 지각 · 공간 기억

  1. 2026-05arXiv 2605.22283

    SOMA ICML 2026 서울 · 요약

    가동형 헤드 카메라로 장면을 스캔해 공간 기억을 만들고, 시야 밖 물체도 찾아 잡는다. 태그: vla spatial-memory out-of-vision

    컬렉션 요약arXiv

3컬렉션 — 묶어서 읽기

여러 편을 한 줄기로 읽는 스터디. 일정·계보·질문은 컬렉션 페이지에, 논문별 자료는 각 스터디 페이지에 있다.

AI² Robotics VLA 논문 6편 읽기한 팀이 2024년부터 낸 논문 여섯 편을 발표순으로 읽으면, 작고 빠른 모델에서 양산 로봇의 두뇌까지 VLA가 자라는 과정이 한 줄로 이어진다. 2026-09-14 ~ 10-04, 주 2편 3주. RoboMamba · FiS-VLA · Video2Act · PosA-VLA · NeuroVLA · SOMA.

4이 사이트로 공부하는 법

  1. 주제 표에서 자리를 잡는다
    1절. 읽으려는 논문이 어느 주제에 있고 이웃 논문이 무엇인지 안다
    10분
  2. 스터디 페이지로 간다
    2절의 링크. 개념(문제 → 아이디어 → 구조 → 학습 → 결과 → 한계)과 실습이 한 장에 순서대로 있다. 더 깊이 볼 곳은 정독 가이드의 해당 절로 링크된다
    2시간
  3. 실습을 돌린다 — 파이썬과 numpy만 있으면 된다
    명령 한 줄, 코드는 GitHub, 노트북은 코랩 버튼. 설치가 막히면 실습 환경
    90분
  4. 컬렉션이 있으면 줄기로 읽는다
    3절. 같은 팀·같은 문제의 논문을 발표순으로 읽으면 한 편씩 읽을 때 안 보이는 것이 보인다
    —

5원본 저장소와 구조

이 사이트는 비공개 저장소 drum-grammer/physical-ai-papers의 생성물이다. 논문 하나가 폴더 하나이고, 파일 이름은 고정이다. 실습 코드만 공개 저장소 physical-ai-study/labs에 그대로 복사된다.

papers/
├── README.md                 논문 인덱스 — 주제별 표 (분류의 정본)
├── queue.md                  읽기 대기열
└── <arXiv>-<slug>/           논문 폴더
    ├── README.md             논문 카드 — 메타 · 주제 · 태그 · 상태
    ├── summary.md            두 쪽 요약
    ├── guide.md              정독 가이드
    ├── notes.md              절별 독해 노트
    ├── lab.md  +  lab/       실습 안내 + 코드 (numpy)      →  /labs/<slug>/
    └── web/                  index · guide · lab .html     →  /papers/<slug>/
collections/<이름>/           스터디 — README(가이드) · web/index.html  →  /collections/<이름>/
논문 요약은 각 arXiv 최신판 본문 기준. 수치와 주장은 각 논문에서 직접 확인하기를 권한다.
